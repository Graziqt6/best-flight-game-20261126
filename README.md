Meridian Run — a 3D chase-view flight game built with three.js. Fly a courier plane through twelve glowing rings over a river valley, mind your fuel, and bring her home to the runway. Keyboard and mouse, desktop browser, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` through any static file server.

## Controls

- W / ↑ climb, S / ↓ descend
- A D / ← → bank and turn
- SHIFT / CTRL throttle up / down
- Mouse drag to look around, R to restart the sortie
